# 솔 야누스·루나 쁘띠 범주와 경험치 획득량 분석

## 분석 설계

- 대상: 2026-06-26과 2026-09-26의 두 범주가 모두 동일한 캐릭터 724명
- 일일 관측치: 66,608개(캐릭터당 92개 변화량)
- 일일 경험치: 레벨업을 반영한 누적 경험치의 연속 날짜 차이
- 추론 단위: 캐릭터(반복 일일 관측을 독립 표본으로 취급하지 않음)
- 30일 누적량: 각 캐릭터의 마지막 30개 일일 변화량 합계
- 신뢰구간: 캐릭터 단위 부트스트랩 2,000회
- 사후검정: Mann–Whitney U, Holm 다중검정 보정, Cliff's delta

## 비모수 검정

Kruskal–Wallis 검정에서 일평균, 중앙값, 활동일 비율, P90, 최근 30일 합계 모두 범주 간 차이가 있었다.

- 솔 야누스: 각 지표의 p값 범위 1.83e-79 ~ 8.20e-72
- 루나 쁘띠: 각 지표의 p값 범위 5.86e-66 ~ 1.28e-54
- 12개 결합 그룹: 각 지표의 p값 범위 8.51e-85 ~ 2.32e-76

솔 야누스의 6개 쌍과 루나 쁘띠의 3개 쌍은 주요 지표에서 모두 Holm 보정 후 유의했다. 일평균 경험치의 Cliff's delta 절댓값은 솔 야누스 비교에서 0.30~0.93, 루나 쁘띠 비교에서 0.34~0.76이었다. 즉 단순 통계적 유의성뿐 아니라 분포 차이도 대체로 중간 이상이었다.

## 레벨·요일 통제 분석

`log1p(일일 경험치) ~ 레벨 + 요일 + 솔 야누스 × 루나 쁘띠` OLS를 적합하고 캐릭터 단위 군집강건 표준오차를 사용했다.

- 레벨+요일 모델 R²: 0.3226
- 범주와 상호작용을 추가한 모델 R²: 0.4123
- 표본 내 증가분: 0.0897
- AIC: 511,086.9 → 501,647.2

다만 이는 인과효과가 아닌 조건부 연관성이다. 특히 `3누스×0석펫`은 3명뿐이어서 일부 개별 상호작용 계수의 신뢰구간이 매우 넓다.

## CatBoost 30일 예측 비교

캐릭터 단위 6:2:2 층화 분할을 세 시드로 반복했다. 각 기준일의 직전 30일 변화량, 목표 요일, 예측일, 현재 레벨을 모든 모델이 공통으로 사용했다.

| 모델 | 추가 범주 | MAE | RMSE | R² |
|---|---|---:|---:|---:|
| A | 없음 | 2.178e12 | 7.356e12 | 0.3137 |
| B | 솔 야누스 | 2.205e12 | 7.345e12 | 0.3154 |
| C | 루나 쁘띠 | 2.185e12 | 7.365e12 | 0.3126 |
| D | 둘 다 | 2.205e12 | 7.379e12 | 0.3099 |

모델 D의 캐릭터 평균 MAE는 A보다 세 반복 모두 높았다. D-A 차이는 약 +115억~+391억 EXP였고, 세 부트스트랩 신뢰구간 중 두 개는 0보다 완전히 컸으며 하나는 0을 포함했다.

## 결론

솔 야누스와 루나 쁘띠 범주는 경험치 획득량 및 활동 빈도와 강하게 연관되어 있다. 하지만 최근 30일의 실제 경험치 패턴을 이미 입력한 CatBoost에서는 두 범주가 새로운 예측 정보를 안정적으로 추가하지 못했다. 따라서 현재 결과는 다음을 지지한다.

1. 두 범주는 유저 활동성의 설명·세분화 변수로 유용하다.
2. 두 범주가 경험치 획득을 인과적으로 증가시킨다고 결론 내릴 수는 없다.
3. 30일 일별 예측 모델에서는 일단 모델 A를 기준으로 삼는 편이 정확도와 단순성 측면에서 낫다.
4. 향후 표본을 늘려 희소 결합 그룹을 보강하거나, 범주가 변경된 시점을 포함하는 종단 자료가 생기면 증분 예측력을 다시 평가할 가치가 있다.
